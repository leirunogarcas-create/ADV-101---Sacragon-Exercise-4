# Scribble Notes

A dark crimson-themed Next.js note-taking app demonstrating React event handling and form validation.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Sign-in checks

- Use a non-empty email address ending in `@gmail.com`.
- The password must be more than 8 characters.
- Validation errors appear below the sign-in button.

This is a front-end demo, not a real authentication system. The email and notes are stored in the browser; the password is not saved. Notes can be created, edited, searched, and deleted. Use **Log out** to return to the sign-in page.
